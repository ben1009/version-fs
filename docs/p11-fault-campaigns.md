# P11 Fault Campaign Evidence Matrix

This index maps every [RFC-002 Section 16.2](../rfcs/002-version-fs-mvp.md#162-failure-injection-gates) failure-injection gate to the deterministic authority, SDK, service, and CLI tests that exercise it, and explicitly notes where real Linux `ublk`/`ext4`/`fsfreeze` or real-S3 runs remain in P12.

| RFC-002 16.2 Gate | Injected Boundary / Fault | Owning Campaign / Test(s) | Verified Outcome & Scope |
| --- | --- | --- | --- |
| Lost create/acquire/attach/barrier replies after commit | `AuthorityAfterCommitBeforeReply`, `AuthorityCommitOutcomeUnknownWithoutCommit` | `fault_campaigns::campaign_worker_loss_recovers_flush_and_fua_and_child_barrier_survives_parent_abort`, `barrier_authority::barriers_reconcile_the_real_authority_gate_on_retry_and_worker_reopen`, `control_authority` | Replay returns original identity/receipt; never allocates a replacement epoch or applies a second barrier. |
| Ordinary writes + FLUSH + FUA + worker loss | Destroy worker barrier dir after `Flush` & `fua: true` write, retain post-FUA volatile write | `fault_campaigns::campaign_worker_loss_recovers_flush_and_fua_and_child_barrier_survives_parent_abort` | Fresh worker with empty cache and zero shared in-memory state recovers flushed and FUA-tagged payloads while losing only post-FUA volatile writes. (Kernel `ublk` preflush/FUA emulation remains in P12.) |
| Paused partial upload + overwrite | `ObjectUploadAfterCommitBeforeReply` after uploading `Extent` to `DirectoryObjectStore`, then `Write` to same offset | `fault_campaigns::campaign_paused_upload_overwrite_does_not_contaminate_sealed_cut` | Pending barrier blocks overtaking writes (`PendingBarrier`), and retry completes the uncontaminated `0xAA` cut on fresh recovery. |
| Failed/lost FLUSH/FUA reply; child barrier survives parent abort | `AuthorityCommitOutcomeUnknownWithoutCommit` on FUA; `FilesystemFreezeAfter` on parent capture | `fault_campaigns::campaign_worker_loss_recovers_flush_and_fua_and_child_barrier_survives_parent_abort` | No completion before durable outcome; committed child barrier remains durable on fresh worker after parent capture aborts. |
| Freeze/seal/commit/reply/thaw crashes + authority restart + capture modes | `AuthorityAfterCommitBeforeReply` on `GenerationDescriptor` upload + full drop (`strong_count == 1`) & WAL reopen of `ToyKvMetadataAuthority` | `fault_campaigns::campaign_authority_restart_around_commit_reconciles_and_persists_exact_capture_modes`, `capture_authority::toy_kv_publish_unknown_outcome_reconciles_before_thawing_and_syncs_local_volume` | Old `OwnerIncarnation` is fenced; `pending_capture.capture_id` is `Committed`; `branch.head == pending_capture.generation_id`; old Generation remains all-zero; `BlockCut`, `FilesystemFrozen`, and `FilesystemCleanUnmount` persist exact modes. (Real `fsfreeze` / `umount` remains in P12.) |
| Drain-time external/producer mutation + handover fencing | Producer commit between pre-drain root read and token CAS; owner handover | `capture_authority::toy_kv_drain_conflict_restarts_and_watchdog_fences_without_hot_rebasing`, `toy_kv_watchdog_recovery_fences_replaced_attachment_without_hot_rebasing` | Token acquisition conflicts; coordinator restarts with fresh ID/drain; replaced grant/attachment is fenced without hot-rebasing. |
| Stale writer/device after handover, reset, deletion, or restart | `move_head`, `delete_branch`, authority restart | `barrier_authority::move_head_and_delete_branch_fence_mounted_volume_without_hot_rebasing`, `fault_campaigns::campaign_authority_restart_around_commit_reconciles_and_persists_exact_capture_modes` | Stale writer/device cannot replace live root, publish, append, trim, or resume mounted device. |
| Lease decision boundary & late ack | `TestClock` expiry across retry vs late ack after commit | `metadata_authority::lease_expiry_is_checked_at_the_gated_decision_and_late_ack_stays_committed` | Expired retry decision is rejected; committed decision with late ack stays committed. |
| >10m slow preparation, 3m renewals, lost renewal reply, expiry | `TestClock` 20s writer / 3m attachment+prep renewals past 12m, `AuthorityAfterCommitBeforeReply` on renewal, then prep-only expiry | `fault_campaigns::campaign_slow_preparation_renewals_idempotent_replay_and_expiry_rejection` | Lost renewal replay returns exact old deadline without double-extension; with writer & attachment kept valid, expired preparation rejects final commit with `ControlError::Expired` and unchanged branch roots/revision. |
| Absent-op abort tombstone vs delayed execution; committed op immune to abort | `abort_operation` before `begin_preparation`; `abort_operation` after commit + branch deletion + `"main"` name reuse | `fault_campaigns::campaign_abort_tombstone_wins_absent_op_while_committed_op_survives_abort_and_name_reuse` | Abort tombstone blocks delayed execution; committed op returns exact original `OperationState::Committed` on abort and after `"main"` deletion/recreation. |
| Authority crash around commit & unknown outcome blocking | Child process exit + WAL reopen | `metadata_authority::{metadata_wal_recovers_after_the_writer_process_exits,metadata_unknown_outcome_child_exits_after_uncertain_result,restart_reconciles_persisted_unknown_outcomes_before_serving_mutations}` | Persisted unknown outcomes reconcile before admitting new mutations; prior-incarnation grants fenced. |
| Native append/artifact races with capture cut & trim | Concurrent append/artifact staging vs capture; whole-batch trim | `native_views_authority`, `retention_reports::provenance_required_evidence_kept_optional_links_excluded_and_disk_spill_exercised` | Batches fall wholly on one side of cut; retained evidence remains readable through trim. |
| Report snapshot loss, missing/corrupt metadata, budget exhaustion, fencing | Snapshot loss, missing branch head generation, fenced protections, budget caps | `retention_reports::{snapshot_loss_before_sealing_aborts_report_id_permanently,sealed_root_scan_excludes_fenced_protections_and_flags_missing_branch_head_generation,uncertain_preparations_budget_exhaustion_and_detail_expiry_behave_explicitly}` | Explicit failure/uncertainty (`Incomplete`, `Aborted`, `Fenced`) with zero object deletions. |
| Corrupt/missing extents/descriptors & provenance integrity | Overwrite real `DirectoryObjectStore` extent `.obj` and `GenerationDescriptor` `.obj` files on disk | `fault_campaigns::campaign_corrupt_objects_and_provenance_integrity_fail_explicitly_without_zero_fill`, `service_lifecycle::provenance_inspection_v2_v1_denied_corrupt_and_sanitized` | Fresh `DurableVolume` read fails on corrupt extent (no zero-fill) and `verify_generation` fails on corrupt descriptor. |
| Capacity exhaustion & unavailable S3/authority | `DirtyCapacityExceeded`, `AuthorityBeforeCommit` | `fault_campaigns::campaign_capacity_exhaustion_and_backend_outages_preserve_recoverable_state`, `retention_reports` | Failures preserve dirty extents and recoverable pending barriers; fresh worker with empty cache recovers flushed data after authority outage. |

> **Scope note:** These campaigns qualify the protocol, coordinator, SDK journals, `ToyKvMetadataAuthority`, and `DirectoryObjectStore` under deterministic fault injection. Real Linux `ublk`/`ext4`/`fsfreeze` kernel-emulation campaigns and real S3 outage/conformance runs remain in P12 / ignored privileged tests.
