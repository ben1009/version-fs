# P11 Fault Campaign Evidence Matrix

This index maps every [RFC-002 Section 16.2](../rfcs/002-version-fs-mvp.md#162-failure-injection-gates) failure-injection gate to the deterministic authority, SDK, service, and CLI tests that exercise it.

| RFC-002 16.2 Gate | Injected Boundary / Fault | Owning Campaign / Test(s) | Verified Outcome & Persisted State |
| --- | --- | --- | --- |
| Lost create/acquire/attach/barrier replies after commit | `AuthorityAfterCommitBeforeReply`, `AuthorityCommitOutcomeUnknownWithoutCommit` | `fault_campaigns::campaign_worker_loss_recovers_flush_and_fua_and_child_barrier_survives_parent_abort`, `barrier_authority::barriers_reconcile_the_real_authority_gate_on_retry_and_worker_reopen`, `control_authority` | Replay returns original identity/receipt; never allocates a replacement epoch or applies a second barrier. |
| Ordinary writes + FLUSH + FUA + combined preflush/data/FUA + worker loss | Destroy worker barrier/cache dir after FLUSH & FUA, retain post-FUA volatile write | `fault_campaigns::campaign_worker_loss_recovers_flush_and_fua_and_child_barrier_survives_parent_abort` | Fresh worker with empty cache recovers earlier writes and FUA-tagged payload; only post-FUA volatile writes are lost. |
| Paused partial-extent upload + overwrite | `ObjectUploadBeforeRequest` during `Flush`, subsequent `Write` | `fault_campaigns::campaign_paused_upload_overwrite_does_not_contaminate_sealed_cut` | Pending barrier blocks overtaking writes (`PendingBarrier`), and retry completes the uncontaminated sealed cut. |
| Failed/lost FLUSH/FUA reply; child barrier survives parent abort | `AuthorityCommitOutcomeUnknownWithoutCommit` on FUA; `FilesystemFreezeAfter` on parent capture | `fault_campaigns::campaign_worker_loss_recovers_flush_and_fua_and_child_barrier_survives_parent_abort` | No completion before durable outcome; committed child barrier remains durable on fresh worker after parent capture aborts. |
| Freeze/seal/commit/reply/thaw crashes + authority restart + capture modes | `AuthorityAfterCommitBeforeReply` on descriptor upload + `ToyKvMetadataAuthority` reopen | `fault_campaigns::campaign_authority_restart_around_commit_reconciles_and_persists_exact_capture_modes`, `capture_authority::toy_kv_publish_unknown_outcome_reconciles_before_thawing_and_syncs_local_volume` | Old `OwnerIncarnation` is fenced; committed Generation reconciles without circular dependence; `BlockCut`, `FilesystemFrozen`, and `FilesystemCleanUnmount` persist exact modes. |
| Drain-time external/producer mutation + handover fencing | Producer commit between pre-drain root read and token CAS; owner handover | `capture_authority::toy_kv_drain_conflict_restarts_and_watchdog_fences_without_hot_rebasing`, `toy_kv_watchdog_recovery_fences_replaced_attachment_without_hot_rebasing` | Token acquisition conflicts; coordinator restarts with fresh ID/drain; replaced grant/attachment is fenced without hot-rebasing. |
| Stale writer/device after handover, reset, deletion, or restart | `move_head`, `delete_branch`, authority restart | `barrier_authority::move_head_and_delete_branch_fence_mounted_volume_without_hot_rebasing`, `fault_campaigns::campaign_authority_restart_around_commit_reconciles_and_persists_exact_capture_modes` | Stale writer/device cannot replace live root, publish, append, trim, or resume mounted device. |
| Lease decision boundary & late ack | `TestClock` expiry across retry vs late ack after commit | `metadata_authority::lease_expiry_is_checked_at_the_gated_decision_and_late_ack_stays_committed` | Expired retry decision is rejected; committed decision with late ack stays committed. |
| >10m slow preparation, 3m renewals, lost renewal replay, expiry | `TestClock` 20s writer / 3m attachment+prep renewals past 12m, then expiry | `fault_campaigns::campaign_slow_preparation_renewals_idempotent_replay_and_expiry_rejection` | Lost renewal replay returns exact old deadline without double-extension; expired preparation rejects final commit. |
| Absent-op abort tombstone vs delayed execution; committed op immune to abort | `abort_operation` before `begin_preparation`; `abort_operation` after commit + branch movement | `fault_campaigns::campaign_abort_tombstone_wins_absent_op_while_committed_op_survives_abort_and_name_reuse` | Abort tombstone blocks delayed execution; committed op stays `Committed` on abort and remains queryable. |
| Authority crash around commit & unknown outcome blocking | Child process exit + WAL reopen | `metadata_authority::{metadata_wal_recovers_after_the_writer_process_exits,metadata_unknown_outcome_child_exits_after_uncertain_result,restart_reconciles_persisted_unknown_outcomes_before_serving_mutations}` | Persisted unknown outcomes reconcile before admitting new mutations; prior-incarnation grants fenced. |
| Native append/artifact races with capture cut & trim | Concurrent append/artifact staging vs capture; whole-batch trim | `native_views_authority`, `retention_reports::provenance_required_evidence_kept_optional_links_excluded_and_disk_spill_exercised` | Batches fall wholly on one side of cut; retained evidence remains readable through trim. |
| Report snapshot loss, missing/corrupt metadata, budget exhaustion, fencing | Snapshot loss, missing branch head generation, fenced protections, budget caps | `retention_reports::{snapshot_loss_before_sealing_aborts_report_id_permanently,sealed_root_scan_excludes_fenced_protections_and_flags_missing_branch_head_generation,uncertain_preparations_budget_exhaustion_and_detail_expiry_behave_explicitly}` | Explicit failure/uncertainty (`Incomplete`, `Aborted`, `Fenced`) with zero object deletions. |
| Corrupt/missing extents/descriptors & provenance integrity | Corrupt descriptor on disk; missing optional link | `fault_campaigns::campaign_corrupt_objects_and_provenance_integrity_fail_explicitly_without_zero_fill`, `service_lifecycle::provenance_inspection_v2_v1_denied_corrupt_and_sanitized` | `verify_generation` / inspection fails explicitly instead of zero-fill; optional-link removal preserves restore. |
| Capacity exhaustion & unavailable S3/authority | `DirtyCapacityExceeded`, `AuthorityBeforeCommit`, `ObjectUploadBeforeRequest` | `fault_campaigns::campaign_capacity_exhaustion_and_backend_outages_preserve_recoverable_state`, `retention_reports` | Failures preserve dirty extents and recoverable pending barriers without eviction or weakened acks. |

> **Scope note:** These campaigns qualify the protocol, coordinator, SDK journals, `ToyKvMetadataAuthority`, and `DirectoryObjectStore` under deterministic fault injection. Real Linux `ublk`/`ext4`/`fsfreeze` and real S3 qualification remain tracked in P12 / ignored privileged tests.
