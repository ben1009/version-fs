# P11 Fault Campaign Evidence Matrix

This index maps every [RFC-002 Section 16.2](../rfcs/002-version-fs-mvp.md#162-failure-injection-gates) failure-injection gate to the deterministic authority, SDK, service, and CLI tests that exercise it, and explicitly distinguishes verified deterministic coverage from items deferred to P12 (real Linux `ublk`/`ext4`/`fsfreeze`, real S3, and remaining race/capacity runs).

| RFC-002 16.2 Gate | Status | Owning Campaign / Existing Test(s) | Verified Outcome & Remaining P12 Scope |
| --- | --- | --- | --- |
| Lost create/acquire/attach/barrier replies after commit | Verified (deterministic) | `fault_campaigns::campaign_worker_loss_recovers_flush_and_fua_and_child_barrier_survives_parent_abort`, `barrier_authority::barriers_reconcile_the_real_authority_gate_on_retry_and_worker_reopen`, `control_authority` | Replay returns original identity/receipt; never allocates a replacement epoch or applies a second barrier. |
| Ordinary writes + FLUSH + FUA + worker loss | Verified (SDK/authority); P12 (kernel `ublk`) | `fault_campaigns::campaign_worker_loss_recovers_flush_and_fua_and_child_barrier_survives_parent_abort`, `versionfs_sdk::barrier::tests::flush_recovers_after_worker_loss_during_an_object_upload` | Fresh worker with empty cache and zero shared in-memory state recovers flushed and FUA-tagged payloads while losing only post-FUA volatile writes. Kernel `ublk` preflush/FUA emulation remains in P12. |
| Upload lost reply + overtaking write | Verified (deterministic) | `fault_campaigns::campaign_upload_lost_reply_blocks_overtaking_write_without_contaminating_cut` | `ObjectUploadAfterCommitBeforeReply` after `Extent` upload blocks overtaking writes (`PendingBarrier`), and retry completes the uncontaminated cut on fresh recovery. |
| Failed/lost FLUSH/FUA reply; child barrier survives parent abort | Verified (deterministic) | `fault_campaigns::campaign_worker_loss_recovers_flush_and_fua_and_child_barrier_survives_parent_abort` | No completion before durable outcome; committed child barrier remains durable on fresh worker after parent capture aborts. |
| Freeze/seal/commit/reply/thaw crashes + authority restart + capture modes | Verified (SDK/authority); P12 (real `fsfreeze`/`umount`) | `fault_campaigns::campaign_authority_restart_around_commit_reconciles_and_persists_exact_capture_modes`, `capture_authority::toy_kv_publish_unknown_outcome_reconciles_before_thawing_and_syncs_local_volume`, `versionfs_sdk::capture::tests::{watchdog_recovers_crash_while_frozen_without_undoing_child_flush,crash_between_publish_and_thaw_recovers_published_generation_and_syncs_baseline,recover_pending_capture_detached_thaws_and_reconciles_without_volume_handle}` | Full authority drop (`strong_count == 1`) + WAL reopen fences old `OwnerIncarnation`; `recover_pending_capture_detached` thaws and reopens producer admission without duplicating publication; old Generation remains zero; all 3 `CaptureMode`s persist. Real `fsfreeze`/`umount` remains in P12. |
| Drain-time external/producer mutation + handover fencing | Verified (deterministic) | `capture_authority::{toy_kv_drain_conflict_restarts_and_watchdog_fences_without_hot_rebasing,toy_kv_watchdog_recovery_fences_replaced_attachment_without_hot_rebasing}` | Token acquisition conflicts; coordinator restarts with fresh ID/drain; replaced grant/attachment is fenced without hot-rebasing. |
| Stale writer/device after handover, reset, deletion, or restart | Verified (deterministic) | `barrier_authority::move_head_and_delete_branch_fence_mounted_volume_without_hot_rebasing`, `fault_campaigns::campaign_authority_restart_around_commit_reconciles_and_persists_exact_capture_modes` | Stale writer/device cannot replace live root, publish, append, trim, or resume mounted device. |
| Lease decision boundary & late ack | Verified (deterministic) | `metadata_authority::lease_expiry_is_checked_at_the_gated_decision_and_late_ack_stays_committed` | Expired retry decision is rejected; committed decision with late ack stays committed. |
| >10m slow preparation, 3m renewals, lost renewal reply, expiry | Verified (deterministic) | `fault_campaigns::campaign_slow_preparation_renewals_idempotent_replay_and_expiry_rejection`, `control_authority::preparation_renewal_replays_and_expiry_clears_capture_admission` | Lost renewal replay returns exact old deadline without double-extension; with writer & attachment kept valid, expired preparation rejects final commit with `ControlError::Expired` and unchanged branch roots/revision. |
| Abandoned capture/barrier cleanup | Verified (deterministic) | `control_authority::{abandoned_capture_child_authorization_is_reclaimed_by_abort_or_expiry,preparation_renewal_replays_and_expiry_clears_capture_admission}` | Protection expires/aborts, capture admission is released safely, and old handles cannot reacquire rights. |
| Absent-op abort tombstone vs delayed execution; committed op immune to abort | Verified (deterministic) | `fault_campaigns::campaign_abort_tombstone_wins_absent_op_while_committed_op_survives_abort_and_name_reuse` | Abort tombstone blocks delayed execution; committed op returns exact original `OperationState::Committed` on abort and after `"main"` deletion/recreation. |
| Authority crash around commit & unknown outcome blocking | Verified (child-process WAL) | `metadata_authority::{metadata_wal_recovers_after_the_writer_process_exits,metadata_unknown_outcome_child_exits_after_uncertain_result,restart_reconciles_persisted_unknown_outcomes_before_serving_mutations}` | Persisted unknown outcomes reconcile before admitting new mutations; prior-incarnation grants fenced. |
| Native append/artifact races with capture cut & trim | Verified (deterministic) | `native_views_authority`, `retention_reports::provenance_required_evidence_kept_optional_links_excluded_and_disk_spill_exercised` | Batches fall wholly on one side of cut; retained evidence remains readable through trim. |
| Report snapshot loss, missing/corrupt metadata, budget exhaustion, fencing | Verified (deterministic); partial (concurrent report vs pin/reader, queued in P12) | `retention_reports::{snapshot_loss_before_sealing_aborts_report_id_permanently,sealed_root_scan_excludes_fenced_protections_and_flags_missing_branch_head_generation,uncertain_preparations_budget_exhaustion_and_detail_expiry_behave_explicitly}` | Explicit failure/uncertainty (`Incomplete`, `Aborted`, `Fenced`) with zero object deletions. Full concurrent report-vs-pin/reader race test moves to P12. |
| Corrupt/missing extents/descriptors & provenance integrity | Verified (deterministic) | `fault_campaigns::campaign_corrupt_objects_and_provenance_integrity_fail_explicitly_without_zero_fill`, `control_authority::{recorded_capture_binding_is_fingerprinted_published_and_reconciled,capture_publication_rejects_a_verified_graph_from_another_object_namespace}`, `service_lifecycle::provenance_inspection_v2_v1_denied_corrupt_and_sanitized` | Fresh `DurableVolume` read fails on corrupt extent (no zero-fill), `verify_generation` fails on corrupt descriptor, and cross-namespace graphs are rejected. |
| Capacity exhaustion & unavailable S3/authority | Verified (dirty limit & authority outage); P12 (real S3 outage & full disk/cache/queue limits) | `fault_campaigns::campaign_capacity_exhaustion_and_backend_outages_preserve_recoverable_state`, `retention_reports` | Dirty limit and `AuthorityBeforeCommit` preserve recoverable state; fresh worker recovers flushed data after authority outage. Real S3 outages and full disk/cache/queue exhaustion remain in P12. |
